# 🧠 1024 Prompt Engineering Corpus & Architecture Matrix

Welcome to the **1024 Prompt Engineering Corpus**, an open-source, production-grade repository cataloging 1,024 prompt patterns, system instructions, meta-prompts, and token-efficient reasoning templates for modern LLMs (Google Gemini 1.5/2.0, Claude 3.5, OpenAI GPT-4o, DeepSeek).

Curated and maintained by **Marcio Krefta** ([@kreftamarcio](https://github.com/kreftamarcio)) as part of the **GitHub Developer Program** and **AI Skills Hub**.

## 📌 Architecture
- 1,024 discrete prompt specifications and reasoning recipes
- Strictly verified and benchmarked for token efficiency and deterministic output
- Clean Conventional Commits and atomic Pull Requests
